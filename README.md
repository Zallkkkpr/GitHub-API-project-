# 🌤️ GitHub API Project - Live Portfolio

This project uses **GitHub REST API** to automatically fetch and display my latest repositories.

### 🚀 Features
- Live data fetching with `fetch() API`
- No manual project updates needed
- Responsive blue-themed UI
- Real-time GitHub integration

### 💻 Tech Stack
- HTML, CSS, JavaScript
- GitHub REST API
- Open-Meteo Weather API
